# Shamaschizm 26.3 acceptance checklist

Target: Minecraft **26.3**, NeoForge **26.3.0.55-beta**, Java **25**. Baseline: GitHub commit `1caeb78a762d59669dd0cc4390e6ab47822432e0`.

These boxes are manual tests, not claims of completed testing. Use separate installations and a COPY of existing worlds. Record failures by ID with steps and `logs/latest.log`. Test single-player and a dedicated server with two players. Compare unspecified balance/settings with the baseline source.

- [ ] T001: Build with Java 25 and ./gradlew clean build (Windows: gradlew.bat clean build).

## Content sweep

Work through the companion content inventory. For every item/block: obtain, inspect tooltip/icon, use/place, break/drop, save/reload, and check a second client. For every recipe: valid inputs, invalid inputs, recipe book, output components and ingredient consumption. For every entity: spawn, animate, fight/interact, kill/drop and save/reload. For every sound: play, attenuation/category and stop/reload.

A finite checklist cannot prove that every interaction with every other mod is correct. Do the normal-modpack pass after the clean installation passes.
